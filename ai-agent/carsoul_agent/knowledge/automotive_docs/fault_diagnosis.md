# 常见故障诊断

> 类别：故障诊断 · CarSoul Guardian 知识库

## 仪表盘故障灯解读

- **发动机故障灯（黄色发动机图标）**：常亮表示排放系统或发动机电控系统故障，可能伴随抖动、无力、油耗升高。可低速行驶至维修点，但应避免高速和急加速。闪烁表示发动机缺火（misfire），未燃烧混合气进入排气管可损坏三元催化器，应立即减速停车呼叫救援。
- **电池充电指示灯（红色电池图标）**：启动后熄灭为正常。行驶中点亮表示发电机不充电，车辆靠蓄电池供电运行，一般只能维持 20-30 分钟。应立即关闭空调、音响等非必要用电设备，尽快驶往维修点。
- **机油压力报警灯（红色机油壶图标）**：点亮表示机油压力过低，发动机可能严重缺机油或机油泵故障。必须立即停车熄火，继续行驶会导致发动机拉缸报废。停车检查机油尺，补充机油后若灯仍亮则需拖车。
- **ABS 故障灯（黄色 ABS 字样）**：常亮表示 ABS 系统故障，常规制动仍可用但无防抱死功能。可谨慎行驶至维修点，注意保持更大刹车距离。
- **胎压监测灯（黄色胎压图标）**：点亮表示一个或多个轮胎胎压异常。应立即减速，安全停车检查四轮胎压。若伴有感叹号闪烁后常亮，可能为胎压传感器电池耗尽。
- **水温报警灯（红色温度计图标）**：点亮表示发动机温度过高。应立即停车怠速散热，切勿打开水箱盖（高温蒸汽烫伤）。检查冷却液是否泄漏，补充后仍高温则需拖车检修。
- **ESP/ESC 灯**：行驶中闪烁属正常（系统正在介入稳定车身）。常亮表示系统被关闭或故障，湿滑路面需格外谨慎。

## 常见故障码解读

- **P0420 催化器效率低于阈值**：最常见故障码之一。可能原因：三元催化器老化失效、氧传感器故障、排气管漏气。若动力正常可短期行驶，但尾气排放超标年检不过。长期不修油耗会升高。
- **P0171 混合气过稀**：发动机进气量多于燃油量。常见原因：进气管漏气、空气流量计脏污、燃油泵压力不足、喷油嘴堵塞。表现：怠速不稳、加速无力。建议尽快检修，长期过稀运行损伤气门。
- **P0300 随机缺火**：发动机某缸或多缸不点火。原因：火花塞老化、点火线圈损坏、喷油嘴堵塞。伴随发动机抖动、加速顿挫。缺火会损坏三元催化器，应尽快维修。
- **P0128 冷却液温度未达工作温度**：节温器常开无法保持温度，或冷却液不足。会导致暖风不热、油耗升高、积碳增多。
- **P0441 燃油蒸发排放系统异常**：碳罐电磁阀故障或管路漏气。一般不影响行驶但尾气排放超标，需更换碳罐或电磁阀。

## OBD 诊断工具使用

- **工具选择**：入门级蓝牙 OBD 读码器（50-150 元）搭配手机 App 可读取和清除故障码；专业诊断仪（如元征 X-431、道通）可读取数据流和执行元件测试。CarSoul Guardian 支持对接 OBD 数据实时监测。
- **读取故障码**：将 OBD 接口（驾驶位方向盘下方，16 针）插入读码器，打开点火开关至 ON（不启动），在 App 中选择"读取故障码"。
- **区分当前码与历史码**：当前码（Current）表示故障仍存在；历史码（Pending/History）表示曾出现但当前未触发。清除故障码后路试，若再次出现则为真实故障。
- **清除故障码**：维修完成后清除故障码重置系统。若清除后立即复现，说明故障未排除。切勿不修车直接清码掩盖问题。
- **数据流分析**：专业场景下读取氧传感器电压、燃油修正值、 coolant 温度等实时数据，可辅助判断间歇性故障。

## 故障自检流程

1. **观察仪表盘**：记录亮起的故障灯颜色（红/黄）和图标，红灯通常需立即停车，黄灯可谨慎行驶。
2. **感受异常现象**：记录抖动、异响、异味、动力变化出现的时间、车速和工况（冷车/热车、怠速/加速）。
3. **检查基础项**：机油尺液位、冷却液壶液位、刹车油壶液位、胎压，排除低液位导致的报警。
4. **读取故障码**：用 OBD 工具读取故障码并记录，拍照存档。
5. **初步判断**：根据故障码和现象对照知识库判断严重程度和可能原因。
6. **决定处理方式**：自行可处理（如补胎、加注玻璃水）则处理；需专业维修则预约或拖车。

## 何时拖车与可继续行驶

- **必须拖车（红色高危）**：机油压力灯亮、发动机严重异响或拉缸、变速箱不换挡/打滑、刹车失灵、方向盘突然变重（助力失效）、冷却液泄漏导致高温、闻到焦糊味或看到冒烟、事故后车身结构受损。
- **可低速行驶至维修点（黄色中危）**：发动机故障灯常亮（动力基本正常）、ABS 灯亮、单个传感器故障、轻微异响。应关闭非必要用电设备，避开高速和拥堵，控制在 60km/h 以内就近维修。
- **可继续行驶（低危）**：胎压灯（检查胎压正常后）、保养提醒灯、部分舒适性故障（如音响、车窗）。仍建议择机检修。
- **拖车注意**：自动挡车辆拖车需使用平板拖车整车上板，禁止两轮着地拖曳（会损坏变速箱）。四驱车必须平板拖车。新能源车高压系统故障时拖车需专业人员断电处理。
