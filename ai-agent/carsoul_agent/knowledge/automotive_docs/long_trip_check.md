# 长途出行检查

> 类别：长途出行 · CarSoul Guardian 知识库

## 出发前检查清单

长途出行前建议提前1-2天进行全面检查，确保车辆处于良好状态，避免途中发生故障。

### 轮胎与胎压
- 检查四条轮胎及备胎的胎压，标准值通常在2.2-2.5bar（详见油箱盖或B柱标签），冷胎测量为准。
- 胎面花纹深度不低于1.6mm，磨损指示线露出时必须更换；检查胎面有无鼓包、裂纹、异物扎入，侧壁损伤一律更换。
- 出发前冷胎测量，高速行驶后胎压上升0.2-0.3bar属正常现象。

### 油液检查
- **机油**：冷车状态下检查机油尺，液位在上下刻度之间，颜色发黑或乳化需更换。
- **冷却液**：液位在膨胀壶MIN与MAX之间，不足时补充同型号防冻液，严禁混加不同颜色防冻液。
- **刹车油**：液位正常且颜色透明偏黄，浑浊变黑或含水量超3%建议更换，刹车油关乎行车安全不可马虎。
- **玻璃水**：加满备用，长途高速虫胶多消耗量大，建议随车备一瓶。

### 灯光与雨刮
- 逐一检查近光、远光、雾灯、转向灯、刹车灯、倒车灯、牌照灯是否正常工作，夜间长途灯光是生命线。
- 雨刮片无老化开裂，刮水无残留水痕和异响，喷水功能正常，雨季出行务必确认。

### 刹车系统
- 刹车片厚度不小于3mm，踩刹车无异常抖动、跑偏和金属摩擦异响。
- 手刹（电子手刹）功能正常，坡道驻车可靠，长途山区行驶刹车负荷大需提前确认。

## 新能源车长途规划

### 充电桩规划
- 使用导航App提前规划沿途充电站，优先选择高速服务区快充桩，避免下高速绕路浪费时间。
- 避免连续行驶至电量低于20%，预留30%以上电量应对堵车、低温、绕路等突发情况。
- 关注充电桩运营商覆盖情况，建议注册2-3个主流App（国家电网、特来电、星星充电），节假日出行提前查看服务区排队情况，必要时提前1-2个服务区充电。

### 续航管理
- 高速行驶风阻大，实际续航通常比NEDC/CLTC标称值低20%-40%，120km/h比100km/h电耗高约30%。
- 冬季低温环境续航再降20%-30%，开暖风影响更大，热泵空调车型冬季表现优于PTC加热车型。
- 建议将单次充电后行驶里程控制在标称续航的50%-60%以内，宁充勿等。

## 高速服务区间隔参考

- 国内高速公路服务区间隔一般为40-60公里，偏远路段可能间隔80-100公里，出发前查询路线服务区分布。
- 新能源车需重点确认服务区是否有充电桩及可用数量，部分老旧服务区可能仅有慢充或无充电设施。
- 建议油量/电量低于30%时主动进服务区补充，避免错过服务区被动抛锚，节假日服务区可能拥堵排队。
- 夜间和恶劣天气行驶时更应提前补能，部分服务区夜间可能缩减服务。

## 长途驾驶疲劳管理

- 连续驾驶每2小时应停车休息15-20分钟，法规规定连续驾驶不得超过4小时、每次休息不少于20分钟。
- 休息时下车活动、拉伸、补充水分，避免在车内刷手机，适度活动可有效缓解腰背疲劳。
- 避免午后13:00-15:00和深夜0:00-6:00等生理低谷时段长途驾驶，事故率显著高于其他时段。
- 出现频繁打哈欠、视线模糊、车道偏离、记忆断片时，必须立即就近服务区休息，切勿硬撑。
- 车载AI守护系统可实时监测驾驶员面部状态和驾驶行为，疲劳时主动提醒并推荐前方服务区，长途出行建议开启此功能。
