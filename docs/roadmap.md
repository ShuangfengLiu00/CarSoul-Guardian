## 各阶段产出

- **规划阶段（TASK001-005）**：产品定位、PRD、Demo 方案、技术架构、数据库设计文档（HTML）。
- **工程阶段（TASK006）**：前后端分离工程骨架、AI Agent 模块、Docker、基础页面与 API。
- **数据阶段（TASK007）**：车辆数字生命档案、健康记录、用车行为、保养记录等核心表与迁移。
- **智能阶段（TASK008）**：AI 车辆医生 · 多智能体专家会诊、LangGraph 风格状态图工作流、Trace 追溯、守护工具层。
  - 定位升级：从「五子 Agent 闭环」升级为「AI 车辆医生 + 多智能体专家系统」，采用主治医生 + 专科专家会诊模型
  - 五子 Agent 诊疗闭环：问诊(perception) → 专家会诊(diagnosis) → 风险分级(risk) → 诊断报告(explainer) → 处方随访(service)
  - 多智能体专家面板：动力/底盘/电气/驾驶行为/保养五位专科专家并行会诊，输出结构化意见后由诊断中枢汇总
  - 纯 Python StateGraph（离线可用，API 兼容 LangGraph）
  - 守护非控制：工具层闸门（仅 push_reminder / record_lifecycle / write_suggestion，无控制工具）
  - 完整 GOAI 闭环五步：感知 → 理解 → 推理 → 调用工具 → 执行任务
  - 专家隔离：单个专家失败不影响其余会诊，保证系统鲁棒性
- **知识阶段（TASK009）**：RAG 知识库、向量检索、诊断增强。
  - 三层架构：Embedding(OpenAI→Hash) → Store(ChromaDB→内存) → Retriever(向量+BM25 混合)
  - 8 篇内置知识文档（保养/故障/新能源/驾驶/轮胎刹车/保险法规/新车/二手车），66 个知识片段
  - Agent 集成：知识型问题路由至 RAG，车辆状态问题走五子 Agent 工作流
  - 后端 API：搜索/导入/统计/重建 4 个端点
  - 前端 UI：知识库搜索页面（`/knowledge`），含统计面板、热门问题、结果展示、文档导入
  - 优雅降级：无外部依赖时使用 Hash 嵌入 + 内存向量存储，系统始终可用
  - CLI 工具：`build_knowledge_base.py` 支持构建/搜索/导入/统计
- **闭环阶段（TASK010）**：风险预测闭环、预测持久化、用户反馈、准确率自校准。
  - 数据模型：`RiskPrediction` 持久化预测详情与实际结果，支持全生命周期追溯
  - 正向路径：触发预测 → 五子 Agent 工作流 → 落库 → 关联告警，支持 user/patrol 两种触发来源
  - 反馈闭环：用户提交处置结果（confirmed/false_alarm/no_event/partial）→ 自动计算准确率 → 关闭关联告警 → 记录生命周期事件
  - 主动巡检：`trigger_patrol` 批量为所有活跃车辆发起预测，实现持续守护
  - 准确率统计：按车辆/按风险等级聚合准确率、误报率，输出 `RiskAccuracyStats`
  - 后端 API：预测、反馈、预测详情、列表、统计、巡检 6+ 个端点
  - 优雅降级：Agent 包不可用时退化为"正常"占位预测，闭环仍可运行
- **交付阶段（TASK011）**：Demo 故事模式（五幕剧场）、GOAI 比赛包装文档、5 分钟可演可示。
  - 故事模式页面 `/story`：自动播放 + 手动控制，电影级深色主题
  - 五幕脚本：车辆数字生命首页 → 异常出现 → Agent 分析 → 主动保护 → 服务闭环
  - 完全自包含：模拟数据驱动，无需后端即可演示
  - 比赛包装文档：评分维度对位、演示检查清单、Q&A 准备
